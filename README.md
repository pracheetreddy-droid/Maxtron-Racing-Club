# MAXTRON Racing Club — Website

A dark, blue-accented racing-themed website for MAXTRON Racing Club (NMIT), built with
plain HTML/CSS/JS — no build step, no framework, works on GitHub Pages for free.

## File structure

```
maxtron-site/
├── index.html         
├── css/style.css       
├── js/content.js         
├── js/main.js            
└── assets/images/        
```
